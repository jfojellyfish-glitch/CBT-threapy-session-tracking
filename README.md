# Fieldnotes v2 — installable local practice journal

Upload all files to the root of a dedicated GitHub repository; Settings → Pages → Deploy from a branch → main / root. Open HTTPS URL on your phone; Safari Share → Add to Home Screen → Open as Web App (if shown). Android Chrome menu → Install app / Add to Home screen. Offline app shell is cached after the first successful online load. External audio/video requires internet.

Tracking: 7/30-day mood, paired tension changes, sleep, practice days, report printing. One entry per exercise per day; values are a current worksheet, not a longitudinal record. Backup in History as JSON; restore replaces local records. Keep backups private.

No server, login, analytics, or cloud sync. Records remain unencrypted in localStorage, on this browser/origin; a home-screen app can have separate storage. Use a dedicated origin where possible, not a shared GitHub Pages origin with unrelated code. Clearing data, browser eviction or changing devices can lose records. Never commit private notes, backups, therapist emails or handouts. Public repository contains generic app code only. External links are third-party services. Not an NHS service and not a clinical monitoring or emergency tool.

Same storage key and version as v1 for continuity on the same origin/browser. Back up before updating.
